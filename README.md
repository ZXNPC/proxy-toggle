# ProxyToggle 🔌

**一键切换 Windows 系统代理的小工具**

按下快捷键即可开启/关闭系统代理，屏幕右下角常驻指示器实时显示状态。

</div>

## 特性

- ⚡ 快捷键一键开关系统代理（默认 `Ctrl+Alt+P`，可在设置中自定义）
- 🖥️ 屏幕右下角常驻指示器，显示"代理已打开"（黑底绿字、置顶、点击穿透）
- 🎨 图形化设置：代理地址、快捷键、提示开关、透明度/字号滑块，支持一键还原默认
- 🚀 开机启动开关
- 🔄 切换后立即刷新系统代理设置，无需重启浏览器
- 📄 首次运行自动生成配置文件，也支持手动编辑

## 快速开始

1. 下载最新的 `ProxyToggle.exe`
2. 双击运行，按 `Ctrl+Alt+P` 即可切换代理
3. 托盘图标右键 → **设置...** 修改代理地址、快捷键、提示样式、开机启动
4. 首次运行会在程序同目录自动生成配置文件 `config.ini`

> ⚠️ 提示：本工具**不是代理软件**，只负责开关 Windows 系统代理设置。
> 你需要先有可用的代理服务（如 Clash、v2ray 等），然后在设置中填入其监听地址（如 `127.0.0.1:7890`）。

## 使用说明

### 默认快捷键

| 操作 | 快捷键 |
|---|---|
| 切换代理 | `Ctrl+Alt+P` |
| 打开设置 | 托盘菜单 → 设置... |
| 查看状态 | 托盘图标 / 屏幕右下角指示器 |

### 设置界面

托盘图标右键 → **设置...**，可配置：

- **代理地址**：`host:port`（HTTP），或 `socks=host:port`（SOCKS），默认 `127.0.0.1:7890`
- **快捷键**：点击"监听..."后按下新的组合键即可捕获，界面以可读形式显示（如 `Ctrl+Alt+P`）
- **显示提示**：是否显示右下角状态指示器
- **提示透明度 / 字号**：滑块调节（透明度 0–255、字号 8–48），提示框尺寸随字号自动调整
- **还原默认**：一键恢复默认设置（代理 `127.0.0.1:7890`、快捷键 `Ctrl+Alt+P`、透明度 180、字号 16）
- **开机启动**：勾选后随系统启动

### 命令行参数（可选）

适合配合快捷方式或任务计划等高级用法：

```bat
ProxyToggle.exe status   :: 输出当前状态 (ON/OFF)
ProxyToggle.exe toggle   :: 切换一次代理并退出
ProxyToggle.exe gui      :: 打开设置窗口
```

## 配置文件 config.ini

首次运行自动生成，位于程序同目录。也可参考 [config.example.ini](config.example.ini) 手动创建：

```ini
[General]
ProxyAddr=127.0.0.1:7890   ; 代理地址（host:port 或 socks=host:port）
Hotkey=^!p                 ; 切换快捷键（默认值，可在设置界面中修改）

[Indicator]
Show=1                     ; 是否显示提示 (1/0)
Transparency=180           ; 透明度 0~255
FontSize=16                ; 字号（提示框宽高由字号自动计算）

[Startup]
AutoStart=0                ; 开机启动 (1/0)
```

> 修改配置文件后需重启程序生效；用设置窗口修改则立即生效。

## 常见问题（FAQ）

**Q: 快捷键不生效？**
A: 可能与其他软件冲突。打开设置 → 点击"监听..."重新设置快捷键，或检查托盘提示。

**Q: 切换后浏览器/软件没有走代理？**
A: 本工具切换的是 Windows 系统代理。个别软件需重启或重新加载才读取新设置；
脚本已自动刷新系统设置，多数场景即时生效。

**Q: 为什么显示"代理已打开"但实际没生效？**
A: 请确认设置中的代理地址对应的代理软件正在运行且端口正确。

**Q: 杀毒软件/Windows SmartScreen 报毒？**
A: 程序未做代码签名，部分杀软会误报。如遇误报请添加信任，或改用源码方式运行。

**Q: 配置文件用记事本保存后代理地址不生效了？**
A: 某些旧版记事本会把文件保存为"UTF-8 带 BOM"，导致程序读不到第一个小节。
程序已内置自动修复：检测到 BOM 会自动重写为正常格式（内容与注释保留）。

**Q: 开机启动后提示"找不到脚本"？**
A: 请勿移动程序（或脚本）的位置；开机启动默认从程序所在目录运行。
